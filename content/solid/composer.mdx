## Usage

```tsx
import { Composer } from "@/components/ui/composer"
```

```tsx
const [text, setText] = React.useState("")

<Composer value={text} onValueChange={setText} onSubmit={send} />
```

## While a turn runs

The send mark has no block behind it in any state: its brightness says what it will do. With `running`, it is the quiet square that stops the turn, until something is typed, which is then sent behind it.

<ComponentPreview name="composer-running" />

## Footer

`ComposerFooter` is the line under the composer, not in it: settings for the message, not part of what is being written. `ComposerPick` is a choice among a few, shown as its current value and held lit while its menu is open.
